# GitHub Setup — 5 Minutes

1. On GitHub, create a **public** repository named exactly:
   `rosewood-digital-product-ba-case`
2. Upload everything inside this portfolio folder to the repository root.
3. Commit to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Your site should publish at:
   `https://cynthialofficial-ux.github.io/rosewood-digital-product-ba-case/`
8. Add that URL to the CV header or LinkedIn Projects after confirming it is live.
