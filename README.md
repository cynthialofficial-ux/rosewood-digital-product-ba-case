# Rosewood Digital Guest Journey — Business Analyst Portfolio

**Independent case study | Public information only | No Rosewood proprietary data used**

This portfolio demonstrates how I would contribute as a Business Analyst within Rosewood Hotel Group's **Digital Platforms and Experience** team. It is built around Rosewood's publicly stated digital direction: a discovery-led Brand.com experience that brings editorial storytelling and transactions together across rooms, dining, wellness and experiences.

## Case objective

Design the business-analysis package for a **Discovery-to-Booking Continuity** enhancement that preserves guest context as a traveller moves from inspiration to room reservation and then to post-booking experience planning.

The case is not a redesign proposal based on internal performance data. It is a **delivery-readiness exercise** showing how I structure requirements, stakeholders, stories, dependencies, UAT and release measurement.

## What is included

- Product brief and scope
- Stakeholder map / RACI
- User and business-user needs
- Discovery-to-booking journey
- Prioritised backlog
- User stories and Given/When/Then acceptance criteria
- Integration and non-functional requirements
- UAT plan and traceability
- AEM content-readiness considerations
- Release gates and KPI framework
- 30-day contribution plan
- Excel delivery workbook

## Publicly evidenced Rosewood working practices used in the case

Public Rosewood digital-product job postings reference:

- Agile product delivery
- Jira / Confluence (and, at senior levels, Slack)
- Adobe Experience Manager (AEM)
- Backlog prioritisation and sprint planning
- UAT with external vendors
- A/B testing / optimisation roadmaps
- Cross-functional work with Brand, Commercial, IT, CRM, Operations and external agencies

Where the current production vendor is not public (for example the exact live booking / CRS or guest-profile architecture), this portfolio intentionally uses **vendor-neutral integration labels**.
